# B3 native-v3 Student v6 composition

Tome's `native_v3_student_v6` profile is explicit.  The package default stays
`native_v3_student_v5`; no historical package is reclassified and no Student
loader, training policy, batching policy, or architecture behavior is changed.

The profile first materializes the immutable v5 language/tokenizer binding and
then binds a closed v6 behavioral registry: target grid, example registry,
corridor modes and full-grid assignments, selected passport and payload,
authority reference, and a non-authority delivery receipt.  Source material
must already provide the full assignment grid.  Tome rejects a source that
would require synthesized behavioral coordinates.

Contract is pinned to the immutable v0.8.0 release commit
`b3275b8769c36b6261f4f241c47f0066c651e869` (tag `v0.8.0`).  Contract owns
semantic identities, resolver behavior, verified opening, M7 streaming
semantics, and v6 failure codes; Tome invokes it before publication.  This
does not claim a v6 default migration, M8B performance work, B4, canonical
fixture production, or a new research run.

When native Path-B has published its accepted M7 sibling, the authoritative
resource is `output_dir.v4.tgz`, produced beside the legacy `output_dir` by
the terminal M7 v4 publication stage.  V6 copies that exact verified archive
as one package member and declares `selected_exemplar_payload/default` as
`m7_tome_archive`; it never flattens that payload to JSONL.  The ordinary
JSONL projection is retained only for legacy layouts without this sibling.
