## Declared inputs and command

The complete normalized input record is committed at
`tests/fixtures/p6_u1_reduced_burn_inputs.json`.
It freezes the path-bound corpus/source records, corpus and manifest hashes,
source-passport digest, teacher/model/tokenizer identities, vocabulary,
behavioral and corridor policy, sequence and top-k settings, selection budget,
batch/shard/concurrency settings, profile, and Contract identity. The corpus
manifest is reused as a committed input; it is not regenerated beneath each
output directory. Its path-bound source identity therefore remains explicit
and unchanged. Only output and temporary locations vary between runs.

The maintained public command is:

```sh
PYTHONPATH=src:/path/to/RADJAX-Contract/src \
python3 scripts/build_v6_reduced_burn_fixture.py \
  --spec tests/fixtures/p6_u1_reduced_burn_inputs.json \
  --output <OUTPUT_DIR> \
  --compare-output <COMPARISON_OUTPUT>
```

The ordinary production stage intentionally uses the current canonical v2
producer contract selection before packaging its Student-profile v6 output;
the explicit `artifact_contract_version: "v2"` field is frozen in the input
record. This does not change Tome's v2 default or publish a new production
default.

The command runs the existing `build_production_gpu_tome` state machine with
the smoke-tokenizer CPU backend, then the ordinary Student-profile v6
directory and `.tgz` writers. It does not read, scrape, or copy a completed
artifact. With `--compare-output`, it also performs the second fresh build and
writes `REPRODUCIBILITY_PAIR.json`; `FIXTURE_RECEIPT.json` binds that pair
evidence by digest. The generated receipt records the canonical input digest,
