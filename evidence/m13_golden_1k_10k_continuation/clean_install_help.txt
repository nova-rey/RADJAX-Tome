usage: radjax-tome [-h] [--json] [--quiet] [--debug] [--no-color] [--version]
                   {corpus,build,validate,inspect,package,doctor,research,tui}
                   ...

RADJAX-Tome produces teacher-side distillation artifacts. Opinionated
production lifecycle CLI. Recommended commands: build, corpus, validate,
inspect, package, doctor, research, tui Legacy-compatible research commands:
build-fingerprint-corridor-leaderboards, allocate-fingerprint-corridor-
coverage, claim-corridor-and-backfill-global, build-multi-role-selected-
exemplars, pack, unpack, prove-capabilities

positional arguments:
  {corpus,build,validate,inspect,package,doctor,research,tui}
    corpus              Build, validate, and inspect a config-driven corpus v2
                        artifact
    build               Build from a complete canonical M5 config
    validate            Validate a promised production artifact
    inspect             Validate and inspect an artifact
    package             Project a producer workspace into a package
    doctor              Report runtime capability
    research            Access retained engineering commands
    tui                 Open an optional corpus or production wizard

options:
  -h, --help            show this help message and exit
  --json
  --quiet
  --debug
  --no-color
  --version             show program's version number and exit
